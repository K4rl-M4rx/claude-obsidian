# Concept page exemplars（概念页范文）

本目录存放 10 篇用户早期 vault 的概念页，作为概念页**风格与深度的参考基准**
（status: developing 级别的样子）：自适应的节组织、带真实定位符的结果版图、
公式密度、与本库其他主题的关系写法。

硬性约定：

- **它们不属于任何 vault**：不得从任何 wiki 页面链接到本目录，不得计入
  知识图谱/账本/索引；frontmatter 里的 `address:` 是旧库遗留编号，仅作存档。
- 仅作范文引用：生长（grow）概念页时，把对应范文全文交给工人作为风格参照，
  或在主题同源时作为生长底稿素材。
